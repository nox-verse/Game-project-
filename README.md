# FOREST LOG · 포레스트 로그

작은 관심과 추억으로 완성하는 힐링 숲 게임. PC 웹 브라우저용 첫 프로토타입입니다.

## 실행

- Windows: `게임 시작.cmd`를 더블클릭하세요. 서버 창은 게임을 하는 동안 열어두세요.
- 소스 저장소: https://github.com/nox-verse/Game-project-
- 로컬 개발: 이 폴더에서 `node serve.cjs`를 실행하고 `http://127.0.0.1:8782/`로 접속하세요.
- 의존성 설치나 빌드 과정은 없습니다. Node.js는 로컬 서버 실행에만 필요합니다.
- `dist/index.html`을 파일로 바로 열면 브라우저의 모듈·저장 제한이 있을 수 있으니 HTTP 서버를 사용하세요.

## 플레이

1. 반짝이는 들꽃·숲 열매·나뭇잎을 눌러 모으세요. 12초 후 잔디 위의 무작위 위치에 다시 나타납니다. 모은 수량은 장소와 관계없이 공유합니다.
2. 동물을 누르면 선택됩니다. 오른쪽 아래의 `대화` 버튼으로 대화하거나 선물하세요. 선호 선물은 친밀도 +15, 그 외 선물은 +8입니다.
3. 대화로는 30초 간격으로 친밀도 +2를 얻을 수 있습니다. 그 사이에도 대화는 자유롭게 할 수 있습니다.
4. 친밀도 25·60·100에서 관계가 발전하고 일기가 기록됩니다. 최고 친밀도에서는 친구의 특별한 추억을 얻습니다.
5. 꾸미기 메뉴의 작업대에서 다섯 장식을 제작하세요. 제작 후 숲의 + 자리를 눌러 배치합니다.
6. 놓인 장식을 누르면 이동하거나 회수할 수 있습니다. 회수한 장식은 재료 소모 없이 다시 놓을 수 있습니다.
7. 도감과 숲 일기에서 발견과 활동을 돌아보세요.

## 산책과 화면 이동

- 동물을 선택하고 `이동`을 누른 뒤 잔디를 누르면 그곳으로 걸어갑니다. 이동 모드는 한 번의 목적지 선택 후 해제됩니다.
- 이동 버튼을 누르지 않은 상태에서 배경을 클릭하면 동물 선택이 풀립니다. 걷고 있던 선택 동물도 멈춥니다.
- 아이템을 누르면 캐릭터 이동 대신 수집을 우선합니다.
- 위쪽 지도나 화면 양쪽 화살표로 `햇살 숲`, `꽃언덕`, `연못가` 사이를 이동합니다. 동물을 선택한 상태면 그 동물과 함께 이동합니다.
- 빈 배경을 드래그하면 화면을 둘러볼 수 있습니다. 오른쪽 아래 `−`, `+`, `⌂`로 축소·확대·전체 보기를 조절합니다.
- 집은 더 작게, 잔디 공간은 더 넓게 구성했습니다. 세 장소를 각각 꾸밀 수 있고, 장식은 놓은 장소와 위치에 저장됩니다.
- 토끼·사슴은 꽃언덕, 곰·너구리는 연못가에서 처음 만날 수 있습니다. 처음 만난 뒤에도 친구들을 다른 장소로 데려갈 수 있습니다.

도감은 초록 표지와 고리가 있는 책으로 열립니다. `동물`, `아이템`, `꾸미기` 탭을 제공하며, 미발견 동물은 실루엣으로 표시됩니다. `숲속에서 만난 작은 발견 N마리`는 인사를 나눈 동물만 집계하고 전체 수의 분모는 표시하지 않습니다. 빈 실루엣 칸은 앞으로의 만남을 위한 디자인 공간이며 전체 동물 수를 뜻하지 않습니다.

## 저장

진행은 브라우저 `localStorage`의 `forest-log.save.v1`에 자동 저장됩니다. 보유량, 친밀도, 발견 목록, 장소별 장식, 동물의 장소와 위치, 무작위 아이템 위치, 일기와 추억이 유지됩니다. 이전 세 여우 버전의 저장 데이터도 기존 진행을 보존하며 확장됩니다. 브라우저 데이터를 지우면 진행이 사라지므로 설정의 저장 파일 내보내기로 백업하세요. 저장 파일 불러오기는 유효성을 확인하고 교체 전에 확인 창을 표시합니다. 다른 브라우저·사이트 주소의 저장 공간은 공유되지 않습니다. 개인 저장 데이터는 Git 저장소에 포함하지 않습니다.

## 초보자를 위한 수정 위치

- `dist/index.html`: 화면의 기본 뼈대
- `dist/style.css`: 화면의 기본 배치와 움직임
- `dist/storybook.css`: 첨부 참고 이미지에 맞춘 나무·종이 UI, 색상, 글꼴과 작은 화면 대응
- `dist/world.css`: 확장된 지도, 드래그 카메라, 캐릭터 걷기, 세로 책 도감
- `dist/app.js`: 데이터와 게임 기능. `ITEMS` 재료, `DECOR` 제작 비용, `FOXES` 동물 친구와 대화, `AREAS` 장소, `NODES` 수집 종류, `SLOTS` 장식 좌표
- `dist/assets/forest-wide.webp`, `flower-hill.webp`, `quiet-pond.webp`: 장소별 넓은 숲 배경
- `dist/assets/characters-v2/red.png`, `arctic.png`, `tibetan.png`: 참고 이미지에 맞춘 개별 투명 치비 캐릭터
- `dist/assets/animals/rabbit.png`, `bear.png`, `deer.png`, `raccoon.png`: 같은 스타일의 추가 동물 친구들
- `node test-game.cjs`: 핵심 게임 경제와 저장 검증

좌표는 장소별 숲 영역의 백분율입니다. 캐릭터와 배경은 같은 파일명으로 교체하면 됩니다. 캐릭터는 투명 정지 이미지에 CSS 호흡·걷기 움직임과 위치 이동을 적용했습니다. 숲 소리는 사용자가 켠 경우에만 Web Audio로 합성합니다.

Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다. 핵심 게임 이미지와 로직은 외부 서비스 없이 동작합니다.

## 이미지 제작

내장 imagegen 도구로 숲과 캐릭터 시트를 생성하고, 설치된 sprite-gen `slice-sheet` 명령으로 캐릭터를 분리했습니다. 원본 생성 프롬프트는 `asset-prompts.md`에 있습니다. 이미지 자산은 프로젝트 안에 포함되어 있습니다. 현재 버전은 사용자 첨부 이미지 `ffff.png`와 `wff.png`를 그림체 참고로 사용했으며, 큰 머리와 작은 몸의 치비 캐릭터, 동화풍 숲, 나무·종이 패널, 하단 그림 메뉴, 5개 하트 친밀도 창과 책 형태 도감으로 디자인을 수정했습니다. 저장 키와 데이터 형식은 유지했습니다.
